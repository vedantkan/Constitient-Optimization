# Data

The data file is **not included** in this repository. It was provided for a course project and is not redistributed here.

The analysis expects one file in this folder, `fall2022_finalproject.csv`, with 1,252 rows and these 11 columns:

| Column | Description |
|---|---|
| `x1`, `x2`, `x3`, `x4` | Mixture fractions of four coating constituents |
| `v1`, `v2`, `v3`, `v4`, `v5` | Process variables |
| `m` | Machine identifier (A–E) |
| `output` | Corrosion response, between 0 and 1 |
